Um clássico jogo da cobrinha desenvolvido com HTML5, CSS3 e JavaScript puro, otimizado para navegadores desktop e dispositivos móveis.

Funcionalidades Otimizadas
Controles Híbridos: Jogue usando as setas do teclado no PC ou botões táteis no celular.

Sistema de Recorde (High Score): O jogo salva automaticamente sua maior pontuação no navegador usando localStorage.

Efeitos Sonoros: Feedback sonoro gerado via Web Audio API (sem necessidade de arquivos externos) ao comer e ao perder o jogo.

Dificuldade Progressiva: A velocidade da cobra aumenta gradualmente conforme você marca pontos.

Prevenção de Colisão Inválida: Lógica implementada para evitar que a cobra inverta o movimento em 180° e cause "game over" acidental.

Tecnologias Utilizadas
HTML5 Canvas: Para a renderização gráfica do jogo.

JavaScript (ES6+): Lógica de movimento, detecção de colisão e manipulação do DOM.

Web Audio API: Para síntese de áudio em tempo real.

CSS3: Design responsivo com Media Queries e otimizações de toque (touch-action).
